# 🎵 AI Music Generation with Deep Learning (CodeAlpha Task 3)

An intelligent music sequence generation web application built using Python, Flask, TensorFlow (LSTM Neural Networks), and a custom HTML/CSS frontend interface.

## 🚀 Features
* **Deep Learning Model:** Utilizes an LSTM (Long Short-Term Memory) neural network to learn sequence patterns and predict new musical note transitions.
* **Web Interface:** Clean, modern frontend interface that interacts with the backend Python API.
* **Interactive Generation:** Generates real-time note sequences on demand via an API endpoint.

## 🛠️ Technologies Used
* Python
* Flask
* TensorFlow / Keras
* HTML5 / CSS3 / JavaScript
